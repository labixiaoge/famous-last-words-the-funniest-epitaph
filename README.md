## Entry

> I asked for my last words to be 'I told you so.' They refused. So here they are, carved in stone, where nobody can argue back.

126 characters. One line, in the dead person's own voice: he asked for "I told you so" as his last words, was refused — so the epitaph itself is the revenge, carved where nobody can argue back. The joke turns on the stone doing the talking.

## Run

```
node main.ts
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`). Deterministic, no dependencies, no network, no cost.
